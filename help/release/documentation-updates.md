# Documentation updates

This page brings together updates from Adobe Commerce technical documentation on [Experience League](https://experienceleague.adobe.com/en/docs/commerce) and [Adobe Developer](https://developer.adobe.com/commerce/docs/). Use these lists to find new topics, revised guidance, and improvements made in response to reader feedback.

Feedback-driven changes address suggestions or issues raised by readers, such as unclear instructions, missing details, or inaccurate information. For example, feedback led to corrections about support for bundled and grouped products in the [product recommendations documentation](https://experienceleague.adobe.com/en/docs/commerce/product-recommendations/boundaries-limits).

## Provide feedback

Your feedback helps improve the documentation. You can contribute in the following ways:

* On Experience League, use the feedback area at the bottom of a topic to rate its helpfulness and leave a comment. See the [Adobe Docs Contributor Guide](https://experienceleague.adobe.com/en/docs/contributor/contributor-guide/introduction) for instructions on reporting issues and suggesting edits.
* On Adobe Developer, use the public GitHub repository linked from the topic to report a documentation issue or propose an edit.

Include the topic URL and describe what is unclear, missing, or incorrect so that the documentation team can understand your suggestion.
