# Feedback-driven documentation updates

These documentation updates were made in response to feedback. Each project defines the time period covered by its source list.

| Description | Type | Date/source |
| --- | --- | --- |

| Updated Merchandising Rules documentation to rename the All product listings rule type to Default search rule in [Merchandising Rules Overview](https://experienceleague.adobe.com/en/docs/commerce/optimizer/merchandising/rules/overview), [Create and Manage Rules](https://experienceleague.adobe.com/en/docs/commerce/optimizer/merchandising/rules/add), and [Release notes](https://experienceleague.adobe.com/en/docs/commerce/optimizer/release-notes), matching the renamed option in the Admin rule-type menu. | Feedback | [October 16, 2026](https://github.com/AdobeDocs/commerce.en/commit/b5c9b1b4ead9f355cd7438d3a8f1b90ac08b12d1) |
