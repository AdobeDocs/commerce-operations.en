# ACP2E-5005: Bundle product quantities don't update in Admin negotiable quotes

The ACP2E-5005 patch fixes an issue where the quantity of a bundle product option in a negotiable quote reverts to its previous value. This happens when you reconfigure the bundle product in the Admin and then edit the line item quantity. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 is installed. The patch ID is ACP2E-5005. Please note that this issue is scheduled to be fixed in Adobe Commerce B2B 1.5.4. 


## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) B2B 1.5.2-p5

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) B2B >=1.5.0 <1.5.4

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where the quantity of a bundle product option in a negotiable quote reverts to its previous value when the bundle product is reconfigured in the Admin, and the quantity is edited.

<u>Prerequisites</u>:

[!DNL B2B] is installed.

<u>Steps to reproduce</u>:

1. On the Admin sidebar, go to Stores > Settings > Configuration > General > [!DNL B2B] Features. Set Enable Company and Enable [!DNL B2B] Quote to Yes.
1. Create a company account and set a password for its company administrator.
1. Create two simple products.
1. Create a bundle product and assign the simple products to different bundle options. In the Bundle Items section, add at least two options using the Drop-down or Radio buttons input type, and select the User Defined checkbox for each bundle item.
1. Sign in to the storefront as the company administrator.
1. Add the bundle product to the cart multiple times, using different option configurations.
1. Go to the shopping cart and request a quote.
1. On the Admin sidebar, go to Sales > Quotes and open the quote.
1. In the bundle product line item, select Configure. In the configuration dialog, change the individual option quantities, leave the line item quantity unchanged, and click OK.
1. In the Items Quoted section, update the Qty values for the bundle line items.
1. Click Update Prices, then click Proceed to confirm the update.

<u>Expected results</u>:

The quote quantities and prices should update successfully after Update Prices is confirmed, even when bundle products have different option configurations.

<u>Actual results</u>:

The quote quantities and prices are not updated.
