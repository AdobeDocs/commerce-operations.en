# ACP2E-5079: Customer segments match only the first website with global account sharing

The ACP2E-5079 patch fixes the issue where evaluating a customer segment assigned to multiple websites returns matching customers only from the first website when customer accounts are shared globally. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 is installed. The patch ID is ACP2E-5079. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.7-p10

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.4 - 2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where evaluating a customer segment assigned to multiple websites returns matching customers only from the first website when customer accounts are shared globally.

<u>Steps to reproduce</u>:

1. Go to Stores > Settings > Configuration > Customers > Customer Configuration > Account Sharing Options, set Share Customer Accounts to Global.
1. Create two websites, then create registered customer accounts on each website and place orders for those customers.
1. Go to Customers > Segments > Add Segment, create an active segment for registered customers, assign it to both websites, and add an order-history condition that matches the test customers.
1. Save the segment, click Refresh Segment Data, and review the Matched Customers grid.

<u>Expected results</u>:

1. The Matched Customers grid lists all registered customers who satisfy the segment condition across both assigned websites.

<u>Actual results</u>:

1. The grid lists matching customers only from the first assigned website.
