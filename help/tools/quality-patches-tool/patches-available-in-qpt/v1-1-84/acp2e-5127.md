# ACP2E-5127: Saving a company with a non-English Admin locale resets Credit Limit to zero

The ACP2E-5127 patch fixes the issue where saving a company in the Admin resets its Credit Limit to 0 when the Admin user's Interface Locale is not English, for example German. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 is installed. The patch ID is ACP2E-5127. Please note that this issue is scheduled to be fixed in Adobe Commerce B2B 1.5.4.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) B2B 1.5.3

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) B2B >=1.3.3 <1.5.4

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where saving a company in the Admin resets its Credit Limit to 0 when the Admin user's Interface Locale is not English, for example German.

<u>Prerequisites</u>:

[!DNL B2B] is installed.

<u>Steps to reproduce</u>:

1. Set Admin > Stores > Settings > Configuration > General > [!DNL B2B] Features > Enable Company = Yes.
1. # Add a new company in the Admin panel. Set Credit Limit to 1234.56 and click Save.
1. Go to Admin > System > Permissions > All Users, click the Admin user's name, set Interface Locale to German (Germany), and click Save User. Sign in as that user.
1. Reopen the same company, change another field, such as Company Legal Name, without changing Credit Limit, and click Save.
1. Reopen the company and check Credit Limit in the Company Credit section.

<u>Expected results</u>:

1. Credit Limit remains the same.

<u>Actual results</u>:

1. Credit Limit is reset to 0.
