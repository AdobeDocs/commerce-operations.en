# ACP2E-5059: Concurrent cron jobs send duplicate order confirmation emails

The ACP2E-5059 patch fixes the issue where customers receive duplicate order confirmation emails when [!UICONTROL Asynchronous sending] is enabled and two sales email cron jobs process the same order at the same time. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 is installed. The patch ID is ACP2E-5059. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.8-p3

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.8 - 2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Customers receive duplicate order confirmation emails when [!UICONTROL Asynchronous sending] is enabled and two sales email cron jobs process the same order at the same time.

<u>Steps to reproduce</u>:

1. In the Admin, go to **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL Sales]** > **[!UICONTROL Sales Emails]** > **[!UICONTROL General Settings]** and set **[!UICONTROL Asynchronous sending]** to *[!UICONTROL Enable]*.
1. Arrange for two sales email cron workers to process the pending order confirmation concurrently.
1. Place a new storefront order using a valid customer email address and complete checkout.
1. Check the customer's email inbox for order confirmation messages.

<u>Expected results</u>:

Exactly one order confirmation email is delivered for the order.

<u>Actual results</u>:

Two or more identical order confirmation emails are delivered to the customer for the same order, typically within one minute.
