# AC-15494: GraphQL products query returns HTML-escaped product names

The AC-15494 patch fixes the issue where the products query returns product names with HTML-escaped special characters instead of their original characters. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 is installed. The patch ID is AC-15494. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.9.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.8-p5

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where the products query returns product names with HTML-escaped special characters instead of their original characters.

<u>Steps to reproduce</u>:

1. Create a new product with a name including double quotes, e.g. ' 55" 4K UHD Smart TV' and SKU 'testsku'.
1. Submit the following GraphQL query:

   ```
   query {
       products(search: "testsku" ) {
           items {
               sku
               name
               description {
                   html
               }
               short_description {
                   html
               }
   
               price_range {
                   maximum_price {
                       final_price {
                           value
                           currency
                       }
                       regular_price {
                           value
                           currency
                       }
                   }
               }
           }
       }
   }
   ```

<u>Expected results</u>:

1. The products query returns the saved product name with its original double quotation marks.

<u>Actual results</u>:

1. The returned product name contains HTML-encoded double quotation marks instead of the original characters.
