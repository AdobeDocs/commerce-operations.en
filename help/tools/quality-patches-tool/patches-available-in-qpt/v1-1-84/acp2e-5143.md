# ACP2E-5143: GraphQL `route` query renders unrequested CMS page content

The ACP2E-5143 patch fixes the issue where the GraphQL `route` query renders the full CMS page content, including Page Builder widgets and product lists, even when only URL routing fields are requested, which slows down URL resolution. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 is installed. The patch ID is ACP2E-5143. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.7-p9

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.4 - 2.4.7-p10

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where the GraphQL `route` query renders the full CMS page content, including Page Builder widgets and product lists, even when only URL routing fields are requested, which slows down URL resolution.

<u>Prerequisites</u>:

Page Builder is installed.

<u>Steps to reproduce</u>:

1. Go to Admin > **[!UICONTROL Content]** > **[!UICONTROL Elements]** > **[!UICONTROL Pages]** and click **[!UICONTROL Add New Page]**.
1. Enter the page details, set **[!UICONTROL Enable Page]** to **[!UICONTROL Yes]**, and click **[!UICONTROL Edit with Page Builder]** in the **[!UICONTROL Content]** section. Expand **[!UICONTROL Add Content]** in the Page Builder panel and drag a **[!UICONTROL Products]** placeholder onto the stage, or insert a catalog product widget into the page content.
1. In Admin, go to **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]**. In the left panel under **[!UICONTROL General]**, choose **[!UICONTROL Web]**, then expand **[!UICONTROL Default Pages]**. Set **[!UICONTROL CMS Home Page]** to the new page and click **[!UICONTROL Save Config]**.
1. Send the following GraphQL request:

   ```
   query ResolveURL($url: String!) {
     route(url: $url) {
       relative_url
       redirect_code
       type
       ... on CmsPage { identifier __typename }
       ... on ProductInterface { uid __typename }
       ... on CategoryInterface { uid __typename }
       __typename
     }
   }
   ```

1. Use the following variables for the request:

   ```
   { "url": "/" }
   ```

<u>Expected results</u>:

The `route` query returns the requested routing metadata and type-discriminator fields for the CMS homepage without rendering its full content.

<u>Actual results</u>:

1. The `route` query renders the full CMS homepage content even though only routing metadata and type-discriminator fields are requested.
1. Page Builder widgets load product collections, increasing response time and the number of database queries per request.
