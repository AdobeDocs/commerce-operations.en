# ACP2E-5263: Product CSV export stops early and omits products

The ACP2E-5263 patch fixes an issue where a CSV product export can stop before it includes all products, which produces an incomplete file. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 is installed. The patch ID is ACP2E-5263. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.8-p5

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.5 - 2.4.8-p5

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Product exports to CSV can stop before all products are included, which produces an incomplete file.

<u>Steps to reproduce</u>:

1. Ensure the catalog contains multiple products and a secondary store view.
2. In the Admin, go to System > Data Transfer > Export.
3. Set Entity Type to Products and leave Export File Format set to CSV.
4. Leave the export filters blank and do not exclude attributes.
5. Scroll down and click Continue.
6. Wait for the asynchronous export to complete, then download and open the CSV file.

<u>Expected results</u>:

The export completes and produces a CSV that contains every product.

<u>Actual results</u>:

The export aborts partway through, but the Admin indicates that the export file is ready and provides a CSV that is missing some products.
