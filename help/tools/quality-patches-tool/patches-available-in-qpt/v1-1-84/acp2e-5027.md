# ACP2E-5027: Indexers don't finish when application locking uses the file lock provider

The ACP2E-5027 patch fixes the issue where indexers never finish because they keep trying to acquire their own lock when `use_application_lock` is enabled and the file lock provider is configured. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 is installed. The patch ID is ACP2E-5027. This issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.9

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.4 - 2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Indexers never finish because they keep trying to acquire their own lock when `use_application_lock` is enabled and the file lock provider is configured.

<u>Steps to reproduce</u>:

1. In `app/etc/env.php`, enable the application lock for indexers and set the lock provider to file:

   ```
   'indexer' =>
   array (
     'use_application_lock' => true,
   ),
   'lock' =>
   array (
     'provider' => 'file',
     'config' =>
     array (
       'path' => '<magento_root>/var/lock',
     ),
   )
   ```

1. Run the `catalog_product_category` indexer:

   ```
   bin/magento indexer:reindex catalog_product_category
   ```

<u>Expected results</u>:

The `catalog_product_category` reindex completes successfully.

<u>Actual results</u>:

The reindex never completes.
