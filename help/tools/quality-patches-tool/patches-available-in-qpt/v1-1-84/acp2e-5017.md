# ACP2E-5017: GraphQL customer role query fails for customers without a company

The ACP2E-5017 patch fixes the issue where the `role` field of the GraphQL `customer` query returns *Internal server error* for a customer who is not assigned to a company. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 is installed. The patch ID is ACP2E-5017. Please note that this issue is scheduled to be fixed in Adobe Commerce B2B 1.5.4.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) B2B 1.5.3

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) B2B 1.5.0 - 1.5.3

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

The `role` field of the GraphQL `customer` query returns *Internal server error* for a customer who is not assigned to a company.

<u>Prerequisites</u>:

B2B is installed.

<u>Steps to reproduce</u>:

1. In the Admin, go to **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL General]** > **[!UICONTROL B2B Features]**, set **[!UICONTROL Enable Company]** to *[!UICONTROL Yes]*, and click **[!UICONTROL Save Config]**.
1. Create a customer account that is not assigned to a company.
1. Send the following GraphQL query using a valid customer token:

```
   query {
     customer {
       email
       firstname
       role {
         id
         name
       }
     }
   }
```

<u>Expected results</u>:

The query returns the customer data with the `role` set to *null*, without errors.

<u>Actual results</u>:

The query returns *Internal server error*.
