# ACP2E-5242: GraphQL uses the store ID as the website ID during add-to-cart requests

The ACP2E-5242 patch fixes the issue where checking product availability while adding items to the cart displays an error indicating that the website cannot be found. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 is installed. The patch ID is ACP2E-5242. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.9

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Checking product availability while adding items to the cart displays an error indicating that the website cannot be found.

<u>Steps to reproduce</u>:

1. Log in to the Admin panel.
1. Go to **Admin** > **[!UICONTROL Stores]** > **Settings** > **[!UICONTROL All Stores]**, click **[!UICONTROL Create Store View]**.
1. Create a second store view named "store_2", for example.
1. Create an empty guest cart with a GraphQL request using the "Store: store2" HTTP header.
1. Record the returned cart ID.
1. Add a simple product to the cart with a GraphQL request using the "Store: store2" HTTP header, the product SKU, and the cart ID.

<u>Expected results</u>:

The product is successfully added to the cart via the GraphQL request.

<u>Actual results</u>:

The GraphQL request fails and writes the message "The website with id ... that was requested wasn't found. Verify the website and try again." to var/log/exception.log.
