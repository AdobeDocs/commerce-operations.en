# ACP2E-4929: Attribute labels on the Compare Products page display translations from a different store view instead of the current one

The ACP2E-4929 patch fixes the issue where attribute labels on the **[!UICONTROL Compare Products]** page, such as **[!UICONTROL Short Description]**, display translations from a different store view instead of the current store view. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.85 is installed. The patch ID is ACP2E-4929. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.8-p2

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.5 - 2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where attribute labels on the **[!UICONTROL Compare Products]** page, such as **[!UICONTROL Short Description]**, display translations from a different store view instead of the current store view.

<u>Steps to reproduce</u>:

1. Log in to the Admin panel.
1. Create a couple of websites, stores, and store views.
1. Set a custom store label for `short_description` on the other store views.
1. Create at least two products with any value in the **[!UICONTROL Short Description]** field, and assign them to all other websites.
1. Place an order.
1. On one of the storefronts, add at least two products to the compare list.
1. Flush the cache or delete the cache directory.
1. Go to the **[!UICONTROL Compare Products]** page. The correct translation for **[!UICONTROL Short Description]** is displayed.
1. Go to a different storefront that has a different translation for **[!UICONTROL Short Description]**.
1. Add at least two products to the compare list, and go to the **[!UICONTROL Compare Products]** page.
1. Add any product to the shopping cart.
1. Go to the **[!UICONTROL Compare Products]** page again.
1. Check the **[!UICONTROL Short Description]** label.
1. Repeat these steps on any other language website.

<u>Expected results</u>:

The correct translation of the **[!UICONTROL Short Description]** label is displayed on the **[!UICONTROL Compare Products]** page in any store view.

<u>Actual results</u>:

The **[!UICONTROL Compare Products]** page displays translations from a different store view.
