# ACP2E-4929: Attribute labels on the Compare Products page display translations from a different store view instead of the current one

The ACP2E-4929 patch fixes the issue where attribute labels on the Compare Products page display translations from a different store view instead of the current store view. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.85 is installed. The patch ID is ACP2E-4929. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.8-p2

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.5 - 2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where attribute labels on the Compare Products page display translations from a different store view instead of the current store view.

<u>Steps to reproduce</u>:

1. Login to Admin panel.
1. Create a couple of websites, stores and store views.
1. Set a custom store label for short_description on the other store views.
1. Create at least 2 products with the Short Description field populated with any value, and assign them to all other websites.
1. Place the order.
1. For one of the Storefronts add at least 2 products to the compare list.
1. Flush the cache or delete the cache directory.
1. Go to the Compare Products page.
1. The correct translation for Short Description is displayed here.
1. Go to a different Storefront that has a different translation for Short Description.
1. Add at least 2 products to the compare list and navigate to the Compare Products page.
1. Add any product to the shopping cart.
1. Navigate to the Compare Product page.
1. Check the Short Description label.
1. Repeat the same on any other language website.

<u>Expected results</u>:

The correct label translation should be displayed on the Compare Product page in any store view for the Short Description.

<u>Actual results</u>:

Compare Products page displays translations from a different store view.
