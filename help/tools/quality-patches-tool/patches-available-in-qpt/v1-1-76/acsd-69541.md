# ACSD-69541: Cart item quantity can't be updated via GraphQL after reducing product stock in [!UICONTROL Admin]

The ACSD-69541 patch fixes the issue where reducing a product’s quantity in the [!UICONTROL Admin] panel to less than the quantity already added to the shopping cart prevents updating the cart item quantity via GraphQL. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.76 is installed. The patch ID is ACSD-69541. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.9.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.8-p2

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.4 - 2.4.8-p3

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

After a product is added to the shopping cart, reducing its quantity in the [!UICONTROL Admin] panel makes it impossible to update the cart item quantity via GraphQL.

<u>Steps to reproduce</u>:

1. Create a simple product: **SKU** = *p1* with **quantity** = *10*.
1. Reindex to ensure **[!UICONTROL salable quantity]** = *10* exists.
1. Add qty = *10* of the previously created product to the shopping cart by GraphQL request.
1. In the [!UICONTROL Admin] panel, edit the product and reduce its quantity to *5*, then save.
1. Reindex again.
1. Try to update the product qty in the shopping cart to *<= 5* using a GraphQL request.
1. Try to update the product qty in the shopping cart to to *> 5* using a GraphQL request.

<u>Expected results</u>:

The cart item quantity is updated when sufficient quantity is *In Stock*. If insufficient quantity is available, a valid error message is returned in the GraphQL response.

<u>Actual results</u>:

When updating the cart item quantity to *<= 5*, a *success* response from GraphQL occurs, but the product quantity in the shopping cart remains unchanged.
When updating the cart item quantity to *> 5*, an internal server error is returned instead of a valid error message.
