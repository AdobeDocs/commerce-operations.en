# AC-16530: Shopping cart shows inconsistent prices after a scheduled catalog price rule update

The AC-16530 patch fixes the issue where the shopping cart did not consistently reflect scheduled updates to catalog price rules. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 is installed. The patch ID is AC-16530. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.9.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.7-p3

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) >=2.4.4 <2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where the shopping cart did not consistently reflect scheduled updates to catalog price rules.

<u>Prerequisites</u>:

Adobe Commerce with cron jobs running.

<u>Steps to reproduce</u>:

1. Log in to the Admin panel.
1. On the Admin sidebar, go to Stores > Attributes > Product, open the SKU attribute, expand Storefront Properties, set Use for Promo Rule Conditions to Yes, and click Save Attribute.
1. On the Admin sidebar, go to Catalog > Products, click Add Product, choose Simple Product, create simple1 with SKU simple1 and Price 100, and save the product.
1. On the Admin sidebar, go to Marketing > Promotions > Catalog Price Rule and click Add New Rule.
1. Create rule1, set Status to Active, select the applicable website and the NOT LOGGED IN customer group, and expand Conditions.
1. Set the condition to If ALL of these conditions are TRUE: SKU is simple1.
1. Expand Actions, set Apply to Apply as percentage of original, set Discount Amount to 10, and click Save.
1. Open the storefront as a guest, add simple1 to the cart, and open the Shopping Cart page.
1. Verify that the item price and subtotal in the main cart content area and the Summary block are 90.
1. In the Admin panel, go to Marketing > Promotions > Catalog Price Rule, open rule1, and in the Scheduled Changes box click Schedule New Update.
1. Enter the Update Name, Start Date, and End Date, change Actions > Discount Amount to 20, keep the scheduled rule status Active, and click Save.
1. Wait until the scheduled update becomes active, then refresh the Shopping Cart page.

<u>Expected results</u>:

The scheduled 20 percent discount is reflected consistently, and the item price and subtotal in both the main cart content area and the Summary block are 80.

<u>Actual results</u>:

The Summary block shows 80, but the item price in the main cart content area remains 90.
