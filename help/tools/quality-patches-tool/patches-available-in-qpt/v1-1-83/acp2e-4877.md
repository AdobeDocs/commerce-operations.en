# ACP2E-4877: Edit button missing for pending Payment on Account orders in Admin

The ACP2E-4877 patch fixes the issue where orders placed with Payment on Account cannot be edited in the Admin while they are in Pending status. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 is installed. The patch ID is ACP2E-4877. Please note that this issue is scheduled to be fixed in Adobe Commerce B2B 1.5.4.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) B2B 1.5.2-p4

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) B2B >=1.3.4 <1.5.4

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where orders placed with Payment on Account cannot be edited in the Admin while they are in Pending status.

<u>Prerequisites</u>:

Adobe Commerce with the [!DNL B2B] extension. Enable Company is set to Yes, Payment on Account and Cash On Delivery are enabled, and the customer is assigned to a company.

<u>Steps to reproduce</u>:

1. In the Admin, go to Sales > Orders and click Create New Order.
1. Select a customer who is assigned to a company, and add a product.
1. In the Payment Method section, select Payment on Account, and click Submit Order.
1. Open the new order from Sales > Orders.
1. Repeat the steps with Cash On Delivery as the payment method, and open that order.

<u>Expected results</u>:

1. The Edit button is displayed on the order view page for both Pending orders, the one placed with Payment on Account and the one placed with Cash On Delivery.

<u>Actual results</u>:

1. The Edit button is missing for the Pending order placed with Payment on Account, while it is displayed for the Cash On Delivery order.
