# ACP2E-4838: Restricted Admin user can't delete customers from an allowed website

The ACP2E-4838 patch fixes the issue where an Admin user with restricted permissions cannot delete customers from the Customers grid. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 is installed. The patch ID is ACP2E-4838. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.8-p3

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) >=2.4.4 <2.4.10

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

An Admin user with restricted permissions cannot delete customers from the Customers grid.

<u>Steps to reproduce</u>:

1. Under Main Website, create a store named Group A with a store view named Store View A, in addition to the default Main Website Store and Default Store View.
1. Create a customer account through Default Store View so the customer belongs to Main Website and **[!UICONTROL Default Store View]**.
1. Go to **[!UICONTROL System]** > **[!UICONTROL Permissions]** > **[!UICONTROL User Roles]** and click **[!UICONTROL Add New Role]**.
1. In Role Resources, grant Customers > All Customers and its Delete permission.
1. In Role Scopes, select Custom for Main Website and allow Group A only, leaving Main Website Store unselected.
1. Create an Admin user and assign it to the restricted role.
1. Sign in to the Admin as the restricted user.
1. Go to Customers > All Customers.
1. Select the customer and choose Delete from the actions menu.

<u>Expected results</u>:

The restricted Admin user can open and delete the customer, because the customer's website is in the role scope, even though the customer was created in a store view outside the role scope.

<u>Actual results</u>:

The customer is not deleted, and the Admin displays the following error message: More permissions are needed to view this item.
