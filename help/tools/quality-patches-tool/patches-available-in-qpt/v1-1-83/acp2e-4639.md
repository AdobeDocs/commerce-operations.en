# ACP2E-4639: Requisition list items type misspelled in Adobe Commerce GraphQL schema

The ACP2E-4639 patch fixes the issue where the requisition list items type is misspelled in the GraphQL schema. The new `requisition_list_items` field returns the correctly spelled `RequisitionListItems` type, while the older `items` field and the `RequistionListItems` type remain available but are deprecated. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 is installed. The patch ID is ACP2E-4639. Please note that this issue was fixed in Adobe Commerce B2B 1.5.3.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) B2B 1.5.2 - p1

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) B2B >= 1.3.4 < 1.5.3

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

The requisition list items type is misspelled as `RequistionListItems` in the GraphQL schema. The older `items` field and the `RequistionListItems` type remain available but are deprecated.

<u>Prerequisites</u>:

Adobe Commerce with the B2B extension.

<u>Steps to reproduce</u>:

1. Send the following GraphQL introspection query:

   ```
   {
     __type(name: "RequisitionList") {
       fields(includeDeprecated: true) {
         name
         isDeprecated
         type {
           name
         }
       }
     }
   }
   ```

1. In the response, check the type that the `items` field returns.

<u>Expected results</u>:

1. The `requisition_list_items` field returns the correctly spelled `RequisitionListItems` type.
1. The `items` field and the `RequistionListItems` type remain available and are marked as deprecated.

<u>Actual results</u>:

The `items` field returns the misspelled `RequistionListItems` type, and no field returns the correctly spelled `RequisitionListItems` type.
