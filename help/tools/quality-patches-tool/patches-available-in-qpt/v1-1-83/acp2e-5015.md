# ACP2E-5015: Shared catalog save removes product assignments and pricing after a session read error

The ACP2E-5015 patch fixes the issue where saving a shared catalog in the Admin can unintentionally remove assigned products and pricing when required catalog data is unavailable. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 is installed. The patch ID is ACP2E-5015. Please note that this issue is scheduled to be fixed in Adobe Commerce B2B 1.5.4.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) B2B 1.5.2-p4

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) B2B >=1.3.4 <1.5.4

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Saving a shared catalog in the Admin can unintentionally remove assigned products and pricing when required catalog data is unavailable.

<u>Prerequisites</u>:

Adobe Commerce with the B2B extension. **[!UICONTROL Enable Company]** and **[!UICONTROL Enable Shared Catalog]** are set to *Yes*.

<u>Steps to reproduce</u>:

1. On the Admin sidebar, go to **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL General]** > **[!UICONTROL B2B Features]**.
1. Set **[!UICONTROL Enable Company]** to *Yes*.
1. Set **[!UICONTROL Enable Shared Catalog]** to *Yes*.
1. Go to **[!UICONTROL Catalog]** > **[!UICONTROL Shared Catalogs]**, click **[!UICONTROL Add Shared Catalog]**, enter a name, and click **[!UICONTROL Save]**.
1. In the **[!UICONTROL Actions]** column for the new shared catalog, select **[!UICONTROL Set Pricing and Structure]**, click **[!UICONTROL Configure]** if displayed, select all available products, and click **[!UICONTROL Next]**.
1. Click **[!UICONTROL Generate Catalog]**, then click **[!UICONTROL Save]**.
1. Reopen **[!UICONTROL Set Pricing and Structure]** for the shared catalog and verify that the products are assigned in the category tree.
1. While the shared catalog wizard is open, cause the active session storage to return a read error, such as a [!DNL Valkey] session data read error.
1. Click **[!UICONTROL Save]**.
1. Reopen **[!UICONTROL Set Pricing and Structure]** and inspect the category tree and pricing structure.

<u>Expected results</u>:

- The shared catalog save is blocked when the required session data cannot be read.
- Existing product assignments and pricing remain unchanged.

<u>Actual results</u>:

- The shared catalog save completes despite the session data read error.
- The missing session data is treated as empty, removing all assigned products and resetting the shared catalog pricing structure.
