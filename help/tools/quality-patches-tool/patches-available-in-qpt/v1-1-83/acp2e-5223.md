# ACP2E-5223: Catalog Permissions index includes websites excluded from customer groups

The ACP2E-5223 patch fixes the issue where the Catalog Permissions index includes websites that are excluded from a customer group. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 is installed. The patch ID is ACP2E-5223. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.8-p5

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) >=2.4.8 <2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where the Catalog Permissions index includes websites that are excluded from a customer group.

<u>Prerequisites</u>:

**None**

<u>Steps to reproduce</u>:

1. Create Multiple Websites: Main Website, Website2.
2. Create categories.
3. Create products.
4. Create Customer Groups with Exclusions:
5. Create groups via Admin UI: Customers → Customer Groups.
 - Exclude Website2
 - Exclude Main Website

6. Navigate to: Catalog → Categories → Select Category.
7. Scroll to Category Permissions section.
8. Click Add Permission.
Website: All Websites
Customer Group: All Customer Groups
Browsing Category: Allow
Display Product Prices: Allow
Add to Cart: Allow
9. Save category.

<u>Expected results</u>:

Index should only contain valid, allowed website/group combinations.
Excluded combinations should be filtered out during indexing.

<u>Actual results</u>:

The index contains rows for excluded website/group combinations.
