# ACP2E-5223: Catalog Permissions index includes websites excluded from customer groups

The ACP2E-5223 patch fixes the issue where the **[!UICONTROL Category Permissions]** index includes websites that are excluded from a customer group. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 is installed. The patch ID is ACP2E-5223. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.8-p5

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) >=2.4.8 <2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

The **[!UICONTROL Category Permissions]** index includes websites that are excluded from a customer group.

<u>Prerequisites</u>:

**None**

<u>Steps to reproduce</u>:

1. Create multiple websites: Main Website, Website2.
1. Create categories.
1. Create products.
1. Create customer groups with exclusions via the **[!UICONTROL Admin]**: go to **[!UICONTROL Customers]** > **[!UICONTROL Customer Groups]**.
   - Exclude Website2
   - Exclude Main Website
1. Go to **[!UICONTROL Catalog]** > **[!UICONTROL Categories]**, and select a category.
1. Scroll to the **[!UICONTROL Category Permissions]** section.
1. Click **[!UICONTROL Add Permission]**, and set:
   - **[!UICONTROL Website]**: *All Websites*
   - **[!UICONTROL Customer Group]**: *All Customer Groups*
   - **[!UICONTROL Browsing Category]**: *Allow*
   - **[!UICONTROL Display Product Prices]**: *Allow*
   - **[!UICONTROL Add to Cart]**: *Allow*
1. Save the category.

<u>Expected results</u>:

- The index contains only valid, allowed website/group combinations.
- Excluded combinations are filtered out during indexing.

<u>Actual results</u>:

- The index contains rows for excluded website/group combinations.
