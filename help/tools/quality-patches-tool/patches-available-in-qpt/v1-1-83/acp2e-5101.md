# ACP2E-5101: Adobe Commerce B2B installation fails when indexers use Update by Schedule

The ACP2E-5101 patch fixes the issue where installing the Adobe Commerce [!DNL B2B] module failed when indexers were set to **[!UICONTROL Update by Schedule]**. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 is installed. The patch ID is ACP2E-5101. Please note that this issue was fixed in Adobe Commerce 2.4.9.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.6-p15

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) >=2.4.4 <2.4.7

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Installing the Adobe Commerce [!DNL B2B] module fails when indexers are set to **[!UICONTROL Update by Schedule]**.

<u>Prerequisites</u>:

**None**

<u>Steps to reproduce</u>:

1. On the Admin sidebar, go to **[!UICONTROL System]** > *[!UICONTROL Tools]* > **[!UICONTROL Index Management]**. Select the indexers, set **[!UICONTROL Actions]** to **[!UICONTROL Update by Schedule]**, and click **[!UICONTROL Submit]**.
1. Install [!DNL B2B] extension.
1. Enable all [!DNL B2B] modules.
1. Run `bin/magento setup:upgrade`.

<u>Expected results</u>:

The [!DNL B2B] modules are installed successfully, and `bin/magento setup:upgrade` completes without errors when indexers use **[!UICONTROL Update by Schedule]**.

<u>Actual results</u>:

`bin/magento setup:upgrade` fails while installing the [!DNL B2B] modules because it attempts to create a database trigger on the `shared_catalog_product_item` table before the table exists.

## Apply the patch

To apply individual patches, use the following links depending on your deployment method:

* Adobe Commerce or Magento Open Source on-premises: [[!DNL Quality Patches Tool] > Usage](/help/tools/quality-patches-tool/usage.md) in the [!DNL Quality Patches Tool] guide
* Adobe Commerce on cloud infrastructure: [Upgrades and Patches > Apply Patches](https://experienceleague.adobe.com/en/docs/commerce-on-cloud/user-guide/develop/upgrade/apply-patches) in the Commerce on Cloud Infrastructure guide
