# ACP2E-4998: Missing SKU prevents bulk tier price updates for valid products

The ACP2E-4998 patch fixes the issue where the POST `/V1/products/tier-prices` REST API request failed for the entire request when one SKU in the payload did not exist, preventing valid SKUs from being updated. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 is installed. The patch ID is ACP2E-4998. Please note that this issue is scheduled to be fixed in Adobe Commerce .

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.7-p10

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) >=2.4.7 < 2.4.8

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

The POST `/V1/products/tier-prices` REST API request failed entirely when one SKU in the payload did not exist, preventing valid SKUs from being updated.

<u>Prerequisites</u>:

None

<u>Steps to reproduce</u>:

1. Identify one existing product SKU, such as product_dynamic_1, and one SKU that does not exist in the catalog, such as product_dynamic_001.
1. Submit a POST request to `/rest/V1/products/tier-prices` containing both SKUs in the same payload:

   ```
   {
   	"prices": [
   		{
   			"sku": "product_dynamic_1",
   			"customer_group": "General",
   			"quantity": 5,
   			"price": 31.99,
   			"price_type": "fixed",
   			"website_id": 0
   		},
   		{
   			"sku": "product_dynamic_001",
   			"customer_group": "General",
   			"quantity": 5,
   			"price": 54.49,
   			"price_type": "fixed",
   			"website_id": 0
   		}
   	]
   }
   ```

<u>Expected results</u>:

1. The tier price is saved for the existing SKU.
1. The response reports the missing SKU as an item-level error.

<u>Actual results</u>:

1. The request fails with the error *The product with SKU "%1" does not exist.* for product_dynamic_001.
1. No tier price is saved for the existing SKU.
