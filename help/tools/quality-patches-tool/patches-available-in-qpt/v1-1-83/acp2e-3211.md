# ACP2E-3211: Parallel add-to-cart requests create separate items for the same SKU

The ACP2E-3211 patch fixes the issue where adding the same product to the cart at the same time on the Storefront creates separate items in the cart for the same SKU instead of combining them into a single item. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 is installed. The patch ID is ACP2E-3211. Please note that this issue was fixed in Adobe Commerce 2.4.8.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.5-p7

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.5 - 2.4.7-p10

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Adding the same product to the cart at the same time on the Storefront creates separate items in the cart for the same SKU instead of combining them into a single item.

<u>Steps to reproduce</u>:

1. Create a new product.
2. Create a new customer account, and log in.
3. Go to product page, open **Dev tools** > **Network**, then add the product to the cart.
4. Copy the curl (bash) request of adding product to cart.
5. Use copied curl query in two console instances to trigger it as quickly as possible twice.

<u>Expected results</u>:

- The product is added as a single cart item, with `qty=2`.

<u>Actual results</u>:

- The product is added as two separate cart items.
