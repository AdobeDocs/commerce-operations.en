# ACP2E-5248: Admin users without [!UICONTROL Edit Product Status] permission see deprecation error on [!UICONTROL Add Product] page on PHP 8.5

The ACP2E-5248 patch fixes the issue where Admin users without the [!UICONTROL Edit Product Status] permission see the *null as array offset* deprecation error when opening the [!UICONTROL Add Product] page on PHP 8.5. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 is installed. The patch ID is ACP2E-5248. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.9

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.5 - 2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Admin users without the [!UICONTROL Edit Product Status] permission see the *null as array offset* deprecation error when opening the [!UICONTROL Add Product] page on PHP 8.5.

<u>Prerequisites</u>:

Adobe Commerce running on PHP 8.5

<u>Steps to reproduce</u>:

1. In the Admin panel, go to **[!UICONTROL System]** > **[!UICONTROL Permissions]** > **[!UICONTROL User Roles]**, and click **[!UICONTROL Add New Role]**.
1. On the **[!UICONTROL Role Info]** tab, enter a **[!UICONTROL Role Name]** and your password in **[!UICONTROL Your Password]**.
1. On the **[!UICONTROL Role Resources]** tab, set **[!UICONTROL Resource Access]** to *Custom*, select **[!UICONTROL Catalog]** > **[!UICONTROL Inventory]** > **[!UICONTROL Products]**, clear **[!UICONTROL Edit Product Status]** under it, and click **[!UICONTROL Save Role]**.
1. Go to **[!UICONTROL System]** > **[!UICONTROL Permissions]** > **[!UICONTROL All Users]**, and click **[!UICONTROL Add New User]**.
1. Fill in the required fields on the **[!UICONTROL User Info]** tab, select the new role on the **[!UICONTROL User Role]** tab, and click **[!UICONTROL Save User]**.
1. Sign out, and sign in to the Admin panel as the new user.
1. Go to **[!UICONTROL Catalog]** > **[!UICONTROL Products]**, and click **[!UICONTROL Add Product]**.

<u>Expected results</u>:

The [!UICONTROL New Product] page opens with the product form.

<u>Actual results</u>:

Instead of the product form, the [!UICONTROL New Product] page shows a deprecated functionality error: *Using null as an array offset is deprecated, use an empty string instead.*
