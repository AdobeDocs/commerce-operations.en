# ACP2E-5248: Admin users without Edit Product Status permission see deprecation error on Add Product page on PHP 8.5

The ACP2E-5248 patch fixes the issue where Admin users without the Edit Product Status permission see the "null as array offset" deprecation error when opening the Add Product page on PHP 8.5. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 is installed. The patch ID is ACP2E-5248. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.9

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.5 - 2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where Admin users without the Edit Product Status permission see the "null as array offset" deprecation error when opening the Add Product page on PHP 8.5.

<u>Prerequisites</u>:

Adobe Commerce running on PHP 8.5.

<u>Steps to reproduce</u>:

1. In the Admin panel, go to System > Permissions > User Roles and click Add New Role.
1. On the Role Info tab, enter a Role Name and your password in Your Password.
1. On the Role Resources tab, set Resource Access to Custom, select Catalog > Inventory > Products, clear Edit Product Status under it, and click Save Role.
1. Go to System > Permissions > All Users and click Add New User.
1. Fill in the required fields on the User Info tab, select the new role on the User Role tab, and click Save User.
1. Sign out and sign in to the Admin panel as the new user.
1. Go to Catalog > Products and click Add Product.

<u>Expected results</u>:

1. The New Product page opens with the product form.

<u>Actual results</u>:

1. Instead of the product form, the New Product page shows a Deprecated Functionality error: Using null as an array offset is deprecated, use an empty string instead.
