# ACP2E-3752: Product import throws an undefined array key error when many import operations run

The ACP2E-3752 patch fixes the issue where product import processing throws the error *Warning: Undefined array key "apply_to"* when many product import operations are created. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 is installed. The patch ID is ACP2E-3752. Please note that this issue is fixed in Adobe Commerce 2.4.9.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.7, 2.4.8-p5

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.7 - 2.4.8-p5

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where product import processing throws the error *Warning: Undefined array key "apply_to"* when many product import operations are created.

<u>Steps to reproduce</u>:

1. In the Admin, go to **[!UICONTROL Stores]** > **[!UICONTROL Attributes]** > **[!UICONTROL Attribute Set]**, open the *Default* attribute set, drag the `color` attribute from **[!UICONTROL Unassigned Attributes]** into a group, and click **[!UICONTROL Save]**.
1. Go to **[!UICONTROL Stores]** > **[!UICONTROL Attributes]** > **[!UICONTROL Product]**, open the `color` attribute, add a couple of options under **[!UICONTROL Manage Options (Values of Your Attribute)]**, and click **[!UICONTROL Save Attribute]**.
1. Run a custom process that creates a new product import model instance many times in the same PHP process. For example, use a console command of a custom module that creates the instance 10,000 times in a loop.

<u>Expected results</u>:

The process finishes without errors.

<u>Actual results</u>:

The process fails, depending on when PHP garbage collection runs, with the error *Warning: Undefined array key "apply_to"*.
