# ACP2E-4973: Switching from In-Store Delivery to another delivery method does not clear store address from cart

The ACP2E-4973 patch fixes the issue where switching from **[!UICONTROL In-Store Delivery]** to another delivery method doesn't clear the store address from the cart. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 is installed. The patch ID is ACP2E-4973. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.8-p5

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.8-p1 - 2.4.8-p5

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Switching from **[!UICONTROL In-Store Delivery]** to another delivery method doesn't clear the store address from the cart.

<u>Prerequisites</u>:

Inventory Management (Multi-Source Inventory) and In-Store Pickup.

<u>Steps to reproduce</u>:

1. In the Admin, go to **[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Sources]** and click **[!UICONTROL Add New Source]**. Enter a **[!UICONTROL Name]** and **[!UICONTROL Code]**, enable *Use as Pickup Location*, enter the **[!UICONTROL Phone]** under **[!UICONTROL Contact Info]**, enter the **[!UICONTROL Country]**, **[!UICONTROL State/Province]**, **[!UICONTROL City]**, **[!UICONTROL Street]**, and **[!UICONTROL Postcode]** under **[!UICONTROL Address Data]**, and save the source.
1. Go to **[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Stocks]** and click **[!UICONTROL Add New Stock]**. Enter a **[!UICONTROL Name]**, select the website under **[!UICONTROL Sales Channels]**, assign the new source under **[!UICONTROL Sources]**, and save the stock.
1. Go to **[!UICONTROL Catalog]** > **[!UICONTROL Products]** and create a simple product. In the **[!UICONTROL Sources]** section, click **[!UICONTROL Assign Sources]**, select the new source, enter a positive Qty, and save the product.
1. Go to **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL Sales]** > **[!UICONTROL Delivery Methods]**, expand **[!UICONTROL In-Store Delivery]**, set **[!UICONTROL Enabled]** to *Yes*, and click **[!UICONTROL Save Config]**.
1. Using GraphQL as a registered customer, generate a customer token (`generateCustomerToken`), get the cart ID (`customerCart`), and add the product to the cart (`addProductsToCart`).
1. Set the cart shipping address to the pickup location by sending only the source code in `pickup_location_code`:

   ```
   mutation {
     setShippingAddressesOnCart(input: {
       cart_id: "<cart_id>"
       shipping_addresses: [{ pickup_location_code: "<source_code>" }]
     }) {
       cart { shipping_addresses { pickup_location_code firstname lastname street city postcode } }
     }
   }
   ```

1. Switch the cart to **[!UICONTROL Flat Rate]** and check `shipping_addresses` in the response:

   ```
   mutation {
     setShippingMethodsOnCart(input: {
       cart_id: "<cart_id>"
       shipping_methods: [{ carrier_code: "flatrate", method_code: "flatrate" }]
     }) {
       cart { shipping_addresses { pickup_location_code firstname lastname street city postcode } }
     }
   }
   ```

1. Set a billing address (`setBillingAddressOnCart`) and a payment method (`setPaymentMethodOnCart`, for example `checkmo`), then run `placeOrder` without setting a new shipping address.

<u>Expected results</u>:

1. After the switch to **[!UICONTROL Flat Rate]**, `pickup_location_code` and the pickup store address are removed from the cart shipping address.
1. You can't place the order until you set a valid home delivery shipping address with `setShippingAddressesOnCart`.

<u>Actual results</u>:

1. After the switch to **[!UICONTROL Flat Rate]**, the cart shipping address still contains `pickup_location_code` and the pickup store address.
1. The order is placed. In **[!UICONTROL Sales]** > **[!UICONTROL Orders]**, the shipping address of the order is the pickup store address, although the delivery method is **[!UICONTROL Flat Rate]**.
