# ACP2E-5118: Page Builder preview doesn't render when Translations cache disabled

The ACP2E-5118 patch fixes the issue where the Page Builder preview fails to render when the Translations cache is disabled. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 is installed. The patch ID is ACP2E-5118. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.8-p5

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.5 - 2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Page Builder preview fails to render when the Translations cache is disabled.


<u>Prerequisites</u>:

Page Builder is required.

<u>Steps to reproduce</u>:

1. In the Admin sidebar, go to **Content** > **[!UICONTROL Elements]** > **[!UICONTROL Blocks]** and click **[!UICONTROL Add New Block]**.
1. Enter `TEST` as the **[!UICONTROL Block Title]** and `test` as the **Identifier**. Use Page Builder to create a row containing text, then click **[!UICONTROL Save & Close]**.
1. Go to **Content** > **[!UICONTROL Elements]** > **[!UICONTROL Pages]**, click **[!UICONTROL Add New Page]**, enter `Test` as the **[!UICONTROL Page Title]**, expand **[!UICONTROL Content]**, and open Page Builder.
1. Add a row to the page, expand **[!UICONTROL Add Content]**, and drag **[!UICONTROL Block]** into the row.
1. Open the Block settings, click **[!UICONTROL Select Block]**, choose the `TEST` block, save the settings, and click **[!UICONTROL Save & Close]** for the page.
1. Go to **[!UICONTROL System]** > **Tools** > **[!UICONTROL Cache Management]**, select **[!UICONTROL Translations]**, set **[!UICONTROL Actions]** to **Disable**, and click **[!UICONTROL Submit]**. In production mode, where the **[!UICONTROL Disable]** action is unavailable, run `bin/magento cache:disable translate` instead.
1. Return to **Content** > **[!UICONTROL Elements]** > **[!UICONTROL Pages]**, edit the `Test` page, and expand **Content**. In the browser's Network panel, check the response to `pagebuilder/stage/preview/?isAjax=true`.
 
<u>Expected results</u>:

The Page Builder preview renders, and the request returns HTTP 200.

<u>Actual results</u>:

The preview request returns HTTP 500 and the preview does not render; Commerce logs the exception `Required parameter 'theme_dir' was not passed`.
