# ACP2E-5050: Viewing or saving RMA in Admin doesn't display RMA number in Action Logs report

The ACP2E-5050 patch fixes the issue where viewing or saving an RMA in the Admin does not display the RMA number in the Action Logs report. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 is installed. The patch ID is ACP2E-5050. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.8-p5

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.6 - 2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where viewing or saving an RMA in the Admin does not display the RMA number in the Action Logs report.

<u>Steps to reproduce</u>:

1. Place an order for a simple product on the Storefront or in the Admin panel.
1. In the Admin panel, go to Sales > Orders, open the order, click Ship, and then click Submit Shipment.
1. On the order page, click Create Returns. On the Return Items tab, click Add Products, select the product, and click Add Selected Product(s) to returns.
1. Enter the Requested quantity, select a Return Reason, Item Condition, and Resolution, and click Submit Returns.
1. Go to Sales > Returns and open the new return.
1. Go to System > Action Logs > Report, set the Action Group filter to Returns, click Search, and check the Details column.

<u>Expected results</u>:

1. The Save entry logged when the return was submitted and the View entry logged when it was opened show its RMA number in the Details column.

<u>Actual results</u>:

1. These entries show only a dash in the Details column, without the RMA number.
