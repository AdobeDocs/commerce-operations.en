# ACP2E-5134: Removing bundled product from Shared Catalog leaves bundle in cart and causes errors at checkout

The ACP2E-5134 patch fixes the issue where removing a product included in a bundle from a company's Shared Catalog leaves the bundle product in the shopping cart and causes an error in the cart and during checkout. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 is installed. The patch ID is ACP2E-5134. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.7-p10

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.6 - 2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where removing a product included in a bundle from a company's Shared Catalog leaves the bundle product in the shopping cart and causes an error in the cart and during checkout.

<u>Prerequisites</u>:

Adobe Commerce with the [!DNL B2B] extension, with Company and Shared Catalog enabled.

<u>Steps to reproduce</u>:

1. In the Admin panel, go to Stores > Settings > Configuration > General > [!DNL B2B] Features, set Enable Company and Enable Shared Catalog to Yes, and click Save Config.
1. Go to Catalog > Products and create three simple products, simple1, simple2, and simple3, and a bundle product, bundle1, with three options that each contain one of the simple products; keep Dynamic Price set to Yes and clear the Required checkbox of each option.
1. Go to Catalog > Shared Catalogs, click Add Shared Catalog, create a Custom shared catalog named Shared Catalog A, and use Set Pricing and Structure to add bundle1, simple1, simple2, and simple3 to it.
1. Go to Customers > Companies, click Add New Company, and create a company with Status set to Active and a Company Admin; in Advanced Settings, set Customer Group to Shared Catalog A.
1. Sign in to the Storefront as the company admin, open bundle1, click Customize and Add to Cart, select all three options, and click Add to Cart.
1. In the Admin panel, open simple2, expand Product In Shared Catalogs, remove Shared Catalog A from Shared Catalogs, and click Save.
1. On the Storefront, as the same customer, open the shopping cart.
1. Open bundle1, select simple1 and simple3, and click Add to Cart.

<u>Expected results</u>:

1. The shopping cart opens with the message "Some of the products below do not have all the required options."; the bundle added before simple2 was removed is marked "The required options you selected are not available." and Proceed to Checkout is hidden until that item is removed.
1. bundle1 with simple1 and simple3 is added to the cart as a new line, and no error page is shown.

<u>Actual results</u>:

1. Opening the shopping cart shows an error page and Add to Cart fails, so the customer cannot proceed to checkout; var/log/exception.log records the warning Undefined array key "sequence-3".
