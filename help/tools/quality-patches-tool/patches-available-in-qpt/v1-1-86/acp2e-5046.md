# ACP2E-5046: Refreshing page while creating order in Admin adds same SKU multiple times

The ACP2E-5046 patch fixes the issue where refreshing the page while creating an order in the Admin adds the same SKU multiple times. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 is installed. The patch ID is ACP2E-5046. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.8-p4

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.5 - 2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where refreshing the page while creating an order in the Admin adds the same SKU multiple times.

<u>Steps to reproduce</u>:

1. In the Admin panel, go to **[!UICONTROL Sales]** > **[!UICONTROL Orders]**.
1. Click **[!UICONTROL Create New Order]**, then select a customer.
1. Click **[!UICONTROL Add Products By SKU]**.
1. Enter the SKU of an existing product and a quantity, then click **[!UICONTROL Add to Order]**.
1. Refresh the page, confirm the form resubmission if the browser asks, and check the quantity of the added SKU.

<u>Expected results</u>:

The SKU remains at the entered quantity after the page is refreshed.

<u>Actual results</u>:

Each page refresh adds the same SKU again, increasing its quantity.
