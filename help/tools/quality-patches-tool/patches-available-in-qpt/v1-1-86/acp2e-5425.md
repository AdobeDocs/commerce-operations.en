# ACP2E-5425: Customers receive duplicate order confirmation emails for same order

The ACP2E-5425 patch fixes the issue where customers receive duplicate order confirmation emails for the same order. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 is installed. The patch ID is ACP2E-5425. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.7-p10

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.5 - 2.4.7-p10

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Customers receive duplicate order confirmation emails for the same order.

<u>Steps to reproduce</u>:

1. In the Admin panel, go to **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL Sales]** > **[!UICONTROL Sales Emails]**, expand **[!UICONTROL General Settings]**, clear **[!UICONTROL Use system value]**, set **[!UICONTROL Asynchronous sending]** to *Enable*, and click **[!UICONTROL Save Config]**.
1. Place a new order on the Storefront using a valid customer email address and complete checkout.
1. Have two processes run the `sales_send_order_emails` cron job at the same time, so that both pick up the queued order confirmation email.
1. Check the customer's email inbox for order confirmation messages.

<u>Expected results</u>:

Exactly one order confirmation email is delivered for the order.

<u>Actual results</u>:

Two identical order confirmation emails are delivered to the customer for the same order.

## Additional steps required after the patch installation

After applying the patch, run `setup:upgrade` to update the `email_sent` columns.

To apply individual patches, use the following links depending on your deployment method:
