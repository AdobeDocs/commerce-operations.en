# ACP2E-4547: Admin can't add a default-catalog product to a quote when it isn't assigned to the user's shared catalog

The ACP2E-4547 patch fixes the issue where an admin could not add a product to a quote through the backend interface when the product was not assigned to a user's shared catalog. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82 is installed. The patch ID is ACP2E-4547. Please note that this issue is scheduled to be fixed in Adobe Commerce B2B 1.5.3.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) B2B 1.5.2-p3

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) B2B >=1.5.0 <1.5.3

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Admin users cannot add products to a quote in the Admin if those products are not assigned to the user's shared catalog.

<u>Prerequisites</u>:

* [!DNL B2B] is installed.
* Shared catalog and company features are enabled.

<u>Steps to reproduce</u>:

1. Create a new customer group.
1. Create a new company and assign it to the newly created customer group.
1. On the Admin sidebar, go to **[!UICONTROL Customers]** > **[!UICONTROL All Customers]**, open the newly created company administrator, and verify that the **[!UICONTROL Customer Group]** value matches the company's customer group.
1. On the Admin sidebar, go to **[!UICONTROL Customers]** > **[!UICONTROL All Customers]** and find the customer in the grid.
1. In the **[!UICONTROL Action]** column, click **[!UICONTROL Edit]**. In the workspace header, click **[!UICONTROL Create Order]**.
1. On the store selector page, use the store view chooser in the upper-left corner to expand the target website or store hierarchy, and then select the store view.
1. On the **[!UICONTROL Create New Order]** page, click **[!UICONTROL Add to Order by SKU]**.
1. Enter the SKU of a product that exists in the primary catalog but is not assigned to the company's shared catalog, and then try to add the product to the order.


<u>Expected results</u>:

Admin users can add products from the default catalog to orders for companies assigned only to regular customer groups, just as they can on the storefront.

<u>Actual results</u>:

The system displays the following error message: *The SKU you entered is not available in the shared catalog. Please check the SKU and try again.*
