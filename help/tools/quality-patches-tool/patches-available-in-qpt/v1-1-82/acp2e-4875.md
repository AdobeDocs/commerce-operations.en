# ACP2E-4875: Admin users logged out when opening customer accounts with large address books

The ACP2E-4875 patch fixes the issue where viewing customer accounts with large address books in the Admin can unexpectedly log out Admin users. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82 is installed. The patch ID is ACP2E-4875. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.8-p3

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.5 - 2.4.9

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

Issue where viewing customer accounts with large address books in the Admin can unexpectedly log out Admin users.

<u>Prerequisites</u>:

A customer account with a large address book containing approximately 5000 or more saved addresses.

<u>Steps to reproduce</u>:

1. Sign in to the Admin.
1. Go to Customers > All Customers.
1. In the Actions column, click Edit for a customer account that has a large address book.
1. On the customer page, open the Addresses tab.

<u>Expected results</u>:

1. The customer page loads successfully and all customer's saved addresses are displayed.

<u>Actual results</u>:

1. The Admin user is unexpectedly signed out.
1. The session exceeds the allowed maximum size, and a log entry similar to "Session size of 1421468 exceeded allowed session max size of 256000" is recorded.
