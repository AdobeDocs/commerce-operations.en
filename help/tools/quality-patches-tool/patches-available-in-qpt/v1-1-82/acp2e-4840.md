# ACP2E-4840: GraphQL products query returns null quantity for in-stock products on custom inventory stocks

The ACP2E-4840 patch fixes the issue where the quantity field in the products GraphQL query returns null for products that are in stock and available for sale on custom inventory stocks. This patch is available when the [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82 is installed. The patch ID is ACP2E-4840. Please note that this issue is scheduled to be fixed in Adobe Commerce 2.4.10.

## Affected products and versions

**The patch is created for Adobe Commerce version:**

* Adobe Commerce (all deployment methods) 2.4.8-p4

**Compatible with Adobe Commerce versions:**

* Adobe Commerce (all deployment methods) 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>The patch might become applicable to other versions with new [!DNL Quality Patches Tool] releases. To check if the patch is compatible with your Adobe Commerce version, update the `magento/quality-patches` package to the latest version and check the compatibility on the [[!DNL Quality Patches Tool]: Search for patches page](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use the patch ID as a search keyword to locate the patch.

## Issue

The quantity field in the products GraphQL query returns null for products that are in stock and available for sale on custom inventory stocks.

<u>Prerequisites</u>:

MSI is enabled.

<u>Steps to reproduce</u>:

1. Create a new source.
1. On the Admin sidebar, go to **[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Stock]**.
1. Click **[!UICONTROL Add New Stock]**.
1. Expand **[!UICONTROL Sales Channels]** and select the **[!UICONTROL Websites]** where the stock is available.
1. Expand **[!UICONTROL Sources]**, click **[!UICONTROL Assign Sources]**, select the source that you want to assign, and click **[!UICONTROL Done]**.
1. On the Admin sidebar, go to **[!UICONTROL Catalog]** > **[!UICONTROL Products]** and open an existing product in edit mode.
1. In the **[!UICONTROL Sources]** section, assign the custom source, set **[!UICONTROL Source Item Status]** to **[!UICONTROL In Stock]**, enter a non-zero value for **[!UICONTROL Qty]**, and save the product.
1. Confirm in **[!UICONTROL Catalog]** > **[!UICONTROL Products]** that the product shows a non-zero **[!UICONTROL Salable Quantity]** for the website assigned to the custom stock.
1. Run the following `products` [!DNL GraphQL] query for that SKU against the store view assigned to the website that uses the custom stock:

   ```
   query {
     products(filter: { sku: { in: ["product_dynamic_1"] } }) {
       items {
         sku
         name
         stock_status
         quantity
         max_sale_qty
       }
     }
   }
   ```

1. Observe the response:

   ```
   {
     "data": {
       "products": {
         "items": [
           {
             "sku": "product_dynamic_1",
             "name": "Simple Product 1",
             "stock_status": "IN_STOCK",
             "quantity": null,
             "max_sale_qty": 10000
           }
         ]
       }
     }
   }
   ```

<u>Expected results</u>:

The GraphQL response returns a non-null quantity value for products that are in stock and salable on the current store/website.

<u>Actual results</u>:

The GraphQL response returns `quantity = null` while `stock_status` = `IN_STOCK` for products that are in stock and salable in the Admin when the store uses a custom MSI stock.
